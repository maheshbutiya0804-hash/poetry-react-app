# Verse & Feeling — Complete React App

Responsive React + TypeScript + Vite implementation of the uploaded design structure.

## Run

```bash
npm install
npm run dev
```

## Included routes

All user-side screens (landing, search, categories, auth, dashboard, card front/back locked/unlocked, ordering, library, profile, forum, poetry requests, orders) and all admin screens (dashboard, cards, bulk upload, users, subscriptions, poetry requests, orders, notifications, community moderation, settings).

The high-resolution Landing Page is implemented closely from the supplied image. The other pages use the same visual system and the structure visible in the overview PDF; exact tiny text, dimensions, and imagery that are unreadable in the overview can be refined when individual high-resolution screen exports are available.
